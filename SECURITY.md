# Security Policy

## Supported versions

Style UI is a static site. The current deployment at https://style.ai.id is supported. There are no versioned releases yet.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting:

https://github.com/miqdadbadjuber/style-ui/security/advisories/new

Do not open a public issue for a security report.

Please include:

- A description of the issue and the affected page.
- Steps to reproduce it.
- The impact you expect.
- A suggested fix, if you have one.
- A safe way to contact you.

## Scope

Reports about the following are in scope:

- Cross-site scripting or script injection through site code.
- Content Security Policy or security header gaps.
- Supply chain issues in third-party scripts or fonts.
- Exposed secrets or credentials in the repository.
- Links that redirect to an unexpected destination.

## Out of scope

The following are out of scope:

- Vulnerabilities in third-party products listed in the directory.
- Issues that require physical access to the visitor's device.
- Reports that only reproduce on unsupported browsers.
- Social engineering or phishing against the maintainer.

## Response

I aim to acknowledge a report within 7 days and to fix confirmed issues as soon as practical. I will credit the reporter in the fix unless you ask to remain anonymous.

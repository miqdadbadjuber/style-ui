## antislop
For UI, copy, people, mobile layout, or code comments work, load the antislop core skill and the skill that matches the task from your agent environment:
- Core: `antislop`
- UI / visual: `antislop-ui`
- Copy & text: `antislop-copywriting`
- People: `antislop-human`
- Mobile / responsive: `antislop-layoutmobile`
- Code comments: `antislop-code`

The skill files are not stored in this repository. Use the copy installed in your own agent setup.
Before starting, ask the user when antislop applies: during the work, or after it is done.
